# khali_poop_collector
RedM resource allowing players to collect different Animal poop for there inventory.

# Requirements
- VORP Core
- VORP Inventory

# Installation
- Extract .zip contents and place the khali_poop_collector folder in your server's resources folder.
- Copy/Cut & Paste the icons found in the khali_poop_collector/items/ folder into the vorp_inventory/html/img/items/ folder.
- Add `ensure khali_poop_collector` to your server.cfg file *after* `ensure vorp_core` and `ensure vorp_inventory`.

# Notes
- You can add more poop props and Items in the Client.lua and Server.lua!
